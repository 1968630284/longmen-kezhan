## 0. 样板核查（先说一条纠正）

- `WPFDevelopersOrg/WPFDevelopers`（原 yanjinhuagood/WPFDevelopers，MIT，1.9k★）：README 里列的是 **Bubble 装饰控件 demo**（Bubblle.gif）和 WpfChatEmojiText，**没有可直接引用的"聊天气泡控件"**；可借鉴的是它的圆角/描边/主题写法，不能当控件直接套。
- `Redlnn/FakeQQ-UI`（Vue，MIT，默认分支 remake）：自称"全方位模仿 QQ NT 气泡"，部分样式直接取自 QQ NT；能取的是**配色/圆角/间距规格**，不能搬代码。
- `vaemc/WpfTimQQ`（WPF 仿 TimQQ，164★，最后一次推送 2022）：整体界面参照，可看气泡左右布局手法。
- 结论同 29 号：**抄样式不抄库、不引依赖**。

依据：GitHub API 仓库元数据 + 两个 README（2026-11-08 16:2x 抓取）。

## 3. 档位呈现

- **不设整卡红框**（47-补3 已作废，本条为准）。
- 档位只在气泡头部放一枚小胶囊：P0 软红 / P1 蓝 / P2 灰，字号 10、圆角 999、padding 6×1。
- 单据卡（传菜口 task 帖）同样只靠胶囊 + 头部文字，不描红。

## 4. 可选中复制（硬要求）

- 现聊天气泡正文是 TextBlock（不可选）。方案：正文改只读 TextBox（`IsReadOnly=true`、边框透明、隐藏插入符、保留选择高亮），模板里只调样式，不动数据绑定。
- 传菜口卡片正文同样处理；截断（MaxHeight 78 + 省略）保留，长文仍靠复制看全。

## 5. 两视图落法

1. 聊天视图：`Refresh-Feed` 里造气泡的那段（bubble + grid + 头像）按上表重排；己方=客官/大厨？按现有 role 判定：客官帖右置蓝泡、大厨/掌柜/GPT 左置白泡，系统/状态帖居中灰字。
2. 传菜口：`New-CbCard` 保留卡片结构，卡内换成"头像 + 名字行（含档位胶囊）+ 气泡正文"，撤掉 1.5px 档位描边、改回中性边。

## 6. 施工序与验收

1. 聊天视图（含可选中）→ 截图（对方/己方/系统各一）自验；
2. 传菜口（含单据卡档位胶囊）→ 截图（对方/己方/系统/单据卡各一）；

## 7. 风险与回滚

- 460 条 feed 全量重排：构造变贵，先做视图内已渲染项（沿用 29 号窗口化结论），不做全量虚拟化。
- 只读 TextBox 会带来光标/选择态样式问题，模板里兜住；回滚点=改前镜像整版。
- 深色主题两套色值需在 Apply-Theme 里补 6 个键；漏一个就花，验收时深浅各截一张。
